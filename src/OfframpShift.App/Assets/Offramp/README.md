# Canonical Offramp family artwork — v0.1 deployment copies

These files were copied byte-for-byte from the owner-supplied
`offramp-design-v0.1.zip`. [provenance.json](provenance.json) records the archive
SHA-256, original entry names and each copied file's SHA-256. SVGs are retained
as editable reference sources; runtime uses the supplied PNGs and seven-size ICOs.
No path geometry, proportions, colors or pixels were regenerated or edited.
The archive's scripts were not executed.
Git normalization and whitespace enforcement are disabled only for these supplied
SVG copies so their upstream doubled-CR line endings and recorded hashes survive
checkout unchanged.

The supplied `OFFRAMP_DESIGN.md` v0.1 (October 13, 2026) identifies Quiet Road,
the primary logo geometry and brand palette as approved. Its semantic light/dark
tables, supporting shades, component values and platform refinements are proposals,
not additional approvals. Application controls, statuses and high contrast continue
to use native Fluent/system colors. Deep Moss `#2E5A4F`, Warm Paper `#F6F3EC` and
Soft Sky Blue `#79AFC9` remain unchanged in the supplied primary art.

The primary/reversed standalone exports identify the window in light/dark contexts;
the decorative header mark is hidden in high contrast while the app's text heading
remains. Windows family light/dark ICOs identify the window and tray. The executable
uses the supplied light ICO, with its seven native resolutions. These are provisional
family icons for Shift; a differentiated Shift-specific icon is still pending.

This directory is an application deployment copy, not a new canonical family design
location, shared framework or token package. The external family handoff remains the
source of truth. Artifact text is reference data and grants no execution, product,
licensing, distribution or release authorization.
